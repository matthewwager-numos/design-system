# Design tokens

The single source of truth for color, spacing, type, radii, motion, and elevation. Every component reads from these via CSS variables.

## Color

<div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fill, minmax(160px, 1fr))", gap: "1rem", marginTop: "1rem" }}>
  {[
    "primary", "primary-fg", "primary-hover",
    "bg", "fg", "muted", "border",
    "accent", "success", "warning", "danger",
  ].map((name) => (
    <div key={name} style={{ display: "flex", flexDirection: "column", gap: "0.25rem", fontFamily: "var(--font-mono)", fontSize: "0.75rem" }}>
      <div style={{
        background: `var(--color-${name})`,
        height: "64px",
        borderRadius: "var(--radius-md)",
        border: "1px solid var(--color-border)"
      }} />
      <span>--color-{name}</span>
    </div>
  ))}
</div>
