# Design tokens

The single source of truth for color, spacing, type, radii, motion, and elevation. Every component reads from these via CSS variables.

## Color

Follows Figma's own two-layer model: **Primitive** (raw ramps) → **Semantic** (aliases a primitive, and swaps to a different primitive in dark mode — toggle your OS/browser color scheme to see it). Components should only ever reach for semantic tokens; primitives exist so semantics have something to alias.

## Typography

Same two-layer model as Color: **Primitive** (raw size/line-height/weight/tracking scale) → **Semantic** (a named text style — Heading or Paragraph — that combines several primitives). Figma's `PP Neue Montreal` typeface isn't licensed/loaded in this repo yet, so specimens below render in `--font-sans` instead — see `Button.css` for the same caveat.

### Typography semantic

Each row applies its token as `font: var(--type-x)` plus `letter-spacing: var(--type-x-tracking)`.

<div style={{ display: "flex", flexDirection: "column", gap: "0.75rem", marginTop: "1rem" }}>

    <div key={name} style={{ display: "flex", alignItems: "baseline", gap: "1rem" }}>
