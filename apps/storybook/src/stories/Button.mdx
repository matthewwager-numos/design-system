# Button

The primary affordance for user actions. Use it whenever you want someone to *do something*.

<Primary />

<Controls />

## When to use

- Submitting forms, confirming actions, navigating to a primary destination.
- Use `variant="primary"` for the *one* most important action on a screen.
- Use `variant="secondary"` for less prominent actions, `"accent"` to draw attention without competing with primary, and `"link"` for the lowest-emphasis, text-only actions.
- Use `variant="destructive"` only for destructive actions (delete, leave, etc.).

## When NOT to use

- For navigation between top-level pages — use a `<Link>` instead.
- For toggles — use `<Switch>` or `<Checkbox>`.
- More than one `primary` button per screen.

## Implementation

```tsx
import { Button } from "@numosai/ui";
import "@numosai/ui/styles.css"; // once, at your app entry

<Button variant="primary" onClick={handleSave}>
  Save changes
</Button>
```

### With an icon

```tsx
import { Save } from "lucide-react";

<Button leadingIcon={<Save size={16} />}>
  Save changes
</Button>
```

## Accessibility

- Renders a real `<button>` element — screen readers and keyboard navigation work for free.
- Focus ring uses `--button-primary-default` and `2px` outline offset. Visible on keyboard focus only (`:focus-visible`).
- Disabled buttons set `aria-disabled` automatically (via the HTML `disabled` attribute) and skip pointer/keyboard interactions.
- Always provide a meaningful `children` label. For icon-only buttons, add `aria-label`.
