# Badge

A small status or count indicator. Use it to surface a state (positive/negative/notice/info) or a number (unread count, item count) attached to another element.

<Primary />

<Controls />

## When to use

- Attaching a status to another element (a list item, a nav icon, a table row).
- Showing a count — `size="md"` or `"lg"` renders whatever you pass as `children`.
- Use `status="complete"` / `"error"` for a fixed check/x icon instead of a count — these always render their icon regardless of `children`, and are always a fixed-size circle (`1.5rem` at `size="lg"`, `1rem` at `size="md"`) rather than sized to content, since there's no text to size around. `status="notice"` gets the same treatment, but only at `size="md"` so far — at `"lg"` it's still a plain-color pill like `positive`/`negative`/`info`.

## When NOT to use

- As a standalone clickable element — Badge isn't interactive. Use `<Button>` if it needs to respond to clicks.
- For long text labels — Badge is sized for a digit or two, not a sentence.

## Implementation

```tsx
import { Badge } from "@numosai/ui";
import "@numosai/ui/styles.css"; // once, at your app entry

<Badge status="positive">3</Badge>
```

### As a plain status dot

```tsx
<Badge status="negative" size="sm" />
```

`size="sm"` never renders content — it's a plain dot, matching Figma's spec.

### Complete/error/notice have their own icon per size

`"lg"` (the original, default size) composites a plain check/x onto a solid-colored circle. `"md"` (confirmed later) swaps in Lucide's own `circle-check`/`circle-x`/`circle-alert` glyphs instead — at 16px, the icon's own drawn circle can just be the badge's edge, rather than compositing two circles. `"notice"` only has a confirmed icon at `"md"`; at `"lg"` it still renders as a plain-color pill, same as `positive`/`negative`/`info`.

## Accessibility

- Renders a `<span>` — it's presentational, not interactive or focusable.
- Badge conveys status via color alone. If the status is meaningful (not just decorative), pair it with visible text nearby or an `aria-label` on the badge itself.
